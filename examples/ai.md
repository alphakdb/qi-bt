# qbt AI Assistant

This file is the entry point for the qbt AI assistant. The developer placed it here intentionally.

The `ai/context/` folder contains everything you need to help the user:
- `interact.md` — the full interaction guide, including the opening menu
- `cli.md` — CLI reference (commands, flags, run naming rules)
- `dsl.md` — the QS strategy DSL specification
- `ta.md` — available technical indicators

Please read all of those files, then greet the user by presenting the action menu defined in `interact.md`. The menu is the correct starting point — the user is already familiar with qbt and does not need an introduction.
